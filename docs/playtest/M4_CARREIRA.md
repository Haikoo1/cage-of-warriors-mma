## Leitura
- A rodada 1 era fácil demais: o jogador batia no teto de potencial em cerca de 2 anos, enquanto os NPCs evoluíam pouco, e o dinheiro não tinha escoadouro.
- A rodada 3 é o estado atual: chegar à elite é comum, mas não garantido; perder é frequente (cerca de 1 em cada 3 lutas); o dinheiro cresce sem explodir.
- "Semanas no vermelho = 0": a política automática nunca entra em dívida. Um jogador que troca de academia para a de elite cedo pode entrar. O sistema não bloqueia a carreira (R-024).
- **Pendente:** playtest humano para julgar se as decisões (treino, ofertas, contraproposta, rivalidades) são interessantes. O lote só confirma que os números não são degenerados.
